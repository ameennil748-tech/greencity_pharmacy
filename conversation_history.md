# Green City Pharmacy - Project History & Reference Guide

This document preserves the key requirements, development history, configurations, and user guide for the **Green City Pharmacy** web application. 

---

## 1. Project Overview & Requirements
The goal of this project was to complete and enhance the static single-page web application for **Green City Pharmacy** owned and operated by Registered Pharmacist **Ameen Ahamad**.

### Implemented Features:
1. **Interactive Medicine Catalog**:
   * Categories filtering (OTC, Vitamins, Essentials, Personal Care) and real-time query search.
   * Tabbed product detailed modals showcasing description, key benefits, active ingredients, usage directions, and warnings/side effects.
2. **Pharmacist Portal & Admin Dashboard**:
   * Locked with a password screen and 6-digit OTP security gate.
   * Simulated phone SMS notification gateway appearing dynamically in the browser to deliver the passcode.
   * Full database control to **Add**, **Edit**, **Delete**, or **Reset** catalog items locally.
   * Payment details setup (UPI ID and bank accounts transfer fields) stored dynamically.
3. **Cart & Checkout Gateway**:
   * Selection between Self-Pickup (Free) or Home Delivery (with a flat ₹30 rider fee).
   * Interactive payment selectors for Cash on Delivery (COD), UPI transfer, or direct Bank accounts.
   * Copy-to-clipboard buttons for fast credentials copying.
   * Automated WhatsApp API message generation compiling items, quantities, totals, delivery details, and payment instructions.
4. **Prescription Upload Zone**:
   * Drag-and-drop region for image or PDF uploads.
   * Dynamically rendered thumbnail image preview for verification before submission.
5. **Interactive FAQ Accordion**:
   * Smoothly animated accordion section solving common pharmacy operations queries.

## 4. User Reference Guide

### A. Customer Order Flow:
1. **Add Items**: Click the `+` icon on any medicine card or open a card's details and click **Add to Order**.
2. **Review Cart**: Click the basket icon in the top-right corner.
3. **Select Delivery**: Choose between Store Pickup or Home Delivery (enter your delivery address).
4. **Choose Payment**: Select UPI or Bank Transfer, and click **Copy** to save the payee's details.
5. **Send via WhatsApp**: Enter your name/phone and click **Order via WhatsApp**. The app compiles your order and opens a pre-composed message in WhatsApp.

### B. Uploading Prescriptions:
1. Scroll down to the **Upload Your Prescription** section.
2. Drag-and-drop or select an image or PDF. If it's an image, a small thumbnail preview will display.
3. Enter your contact details and click **Submit to Pharmacist** to route the request directly to the pharmacist's WhatsApp line.

### C. Pharmacist Admin Management:
1. Click **Portal** in the header.
2. Enter the password `admin123` and the OTP code shown in the SMS banner.
3. **To Add a Product**: Click **Add New Product** in the catalog manager, complete the fields, and click Save.
4. **To Edit/Delete**: Click the pencil icon to modify details or the trash icon to remove the product.
5. **To Update Bank/UPI Coordinates**: Click the **Payment & Security** tab, update the details, and click **Save Configurations**. The changes will immediately show on the customer check-out cart.
